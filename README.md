**[agent-manager](https://github.com/YoanWai/agent-manager)** — Claude Code, Codex, OpenCode
and Grok side by side in one list, each in its own tmux session, still running after you quit.
Live status, foldable project tree, and a diff reviewer where a comment on a line goes
straight back to the agent. Go.

```bash
brew install yoanwai/tap/agent-manager
```
